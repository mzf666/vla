# VLA Tutorial Code

This directory will hold minimal, runnable experiments paired with the blog posts.

Planned experiments:

- `02-world-model-basics`: DreamerV3 / TD-MPC2 smoke-test notes and wrappers.
- `03-embodied-imitation-pipeline`: LeRobot + ACT + PushT commands and logs.
- `04-vlm-to-vla`: SmolVLA smoke test and OpenVLA reading notes.
- `08-research-entry-points`: controlled ablation scripts for small-data experiments.

Keep code small and reproducible. Prefer scripts that can run on CPU or Apple Silicon MPS before adding GPU-only paths.
